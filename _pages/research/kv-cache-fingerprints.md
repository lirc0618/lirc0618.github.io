# 模型变了，KV Cache 中的指纹还在吗？

<p class="research-meta">CIIS 2026 · <a href="{{ '/assets/pdf/How%20Model%20Transformations%20Affect%20Fingerprints%20in%20Transformer%20Key%E2%80%93Value%20Caches.pdf' | relative_url }}">论文 PDF</a></p>

语言模型从下载到部署，常会经历量化、剪枝、权重混合或下游微调。用于核验模型归属的指纹，也会随这些变化受到影响。一个实际问题是：模型经过修改后，原先登记的信号还能被读出来吗？反过来，即使指纹仍能被检测到，模型是否还保留了可用的预测能力？

我们以 Transformer 推理中的 Value 状态为审计通道，用 BCH 纠错编码保护一段短消息，再将编码信号分散到多个坐标。在四个语言模型、三组载波种子和 14 种受控条件下，原生与 INT8 设置均达到 100% 检测率；更强量化和剪枝则暴露出明显的失效边界。

这项工作的重点，是把**消息能否恢复、检测器是否接受、模型预测质量如何**分别报告。它们可能给出不同答案：消息完整恢复，仍可能因信号太弱而未通过核验；指纹检测率保持 100%，也可能伴随预测质量大幅下降。

## 给短消息增加冗余，也约束比较的代价

指纹携带 7 位信息，经 BCH(15,7,5) 编成 15 位码字。该码的最小距离为 5，可以纠正每个码字中至多两位错误。我们利用固定种子确定的置换，将码位交织到 15 个选定的 Value 投影坐标，再以低幅度、低秩的扰动写入权重；推理时从对应的 Value 激活中读取响应。

这样设计有两个考虑。纠错编码为部分坐标受损后恢复消息提供冗余；交织则改变码位与物理坐标的对应关系，减轻局部受损集中影响某些符号的风险。实际收益仍取决于变换产生的错误，不能仅凭纠错能力推断所有部署条件下都有效。

为了判断收益来自哪里，我们同时比较交织 BCH、去掉置换的有序 BCH、交织重复码，以及 7 位消息加 8 个常量填充坐标的未编码方案。四者使用相同的 15 个物理坐标和相同的扰动范数预算，避免将更多坐标或更强信号误算成编码收益。

## 恢复正确消息，只是核验的一部分

读取时，我们对同一文档进行成对的干净与带指纹推理，计算两者激活差与登记载波方向的有符号相关性。BCH 软解码器在全部 128 个候选码字中选择匹配程度最高的一个。

文档要通过核验，必须同时满足两个条件：解出的消息与登记消息一致，且平均有符号相关性大于 0.5。前者检查身份内容，后者检查信号强度。对错误消息产生强响应，或从过弱响应中选中正确消息，都不会单独计作检测成功。

本文因此分别统计带指纹文档的检测率（TPR）、干净文档的误报率（FPR）、消息比特错误率（BER），以及相对原生干净模型的自然对数困惑度变化（Δ log PPL）。最后一项衡量下一词预测的损失，增大表示预测质量下降。这一流程需要读取内部状态并使用配对参考，其证据适用于受控审计环境。

## 哪些变化能承受，哪些会破坏信号

主实验覆盖 Qwen3-0.6B、Qwen2.5-0.5B、Gemma3-1B-IT 和 Llama3.2-1B。每个模型使用三组种子，每组分配 12 篇选择文档、16 篇校准文档，以及 20 对带指纹／干净测试文档。四种载荷与 14 种条件组成 672 个实验条件，共 26,880 次文档事件；重复调用解码器不增加独立观测数。

受控变换包括选定 Value-head 的 INT8、INT4、INT2 量化，与干净权重按不同比例混合，选定投影的 10%、30%、50% 剪枝，以及仅保留部分 token 可见性的缓存遮蔽。以下结果针对交织 BCH，按三组种子取平均。

| 条件 | 四个模型的检测率 | 结果说明 |
| --- | --- | --- |
| 原生、INT8 | 均为 100% | 所测条件下完整通过核验 |
| INT4 | 三个为 100%，Gemma3 为 76.7% | 较低精度开始产生模型差异 |
| INT2 | Qwen3 为 5%，其余为 0% | 强量化通常破坏可恢复信号 |
| 投影剪枝 30% | 78.3%–100% | 部分受损仍可恢复 |
| 投影剪枝 50% | 8.3%–93.3% | 强剪枝下差异明显扩大 |

*数据来自原论文表 1、表 4；每个模型、每组种子含 20 篇带指纹测试文档。表 1 列出的交织 BCH 条件中，观测 FPR 均为 0，不代表任意输入下误报概率为零。*

## 编码的优势主要出现在部分剪枝条件下

我们还用量化索引调制（QIM）建立配对对照：固定模型、种子 2027、坐标、能量预算、校准数据和变换设置，仅比较 BCH 与未编码载荷，并分别测试 0 和 0.25 两个量化偏移。下表保留偏移为 0 的代表性结果，不能与三种子主实验直接混为一组。

| 模型与投影剪枝比例 | BCH 检测率 | 未编码检测率 | 差值及配对 95% 区间 |
| --- | ---: | ---: | --- |
| Qwen3，30% | 60% | 0% | +60 个百分点［40, 80］ |
| Qwen3，50% | 55% | 0% | +55 个百分点［35, 75］ |
| Llama3.2，50% | 100% | 0% | +100 个百分点［100, 100］ |

*来源为原论文表 2、表 3；区间按文档索引配对 bootstrap，不是跨模型或跨种子的总体保证。*

这些对照说明，在部分坐标被剪枝破坏时，冗余能转化为检测收益。原生、INT8 等信号已经完整的条件下，两种载荷通常都能达到 100%，编码没有额外提升空间；INT2 下两者又可能同时失败。交织也并非始终优于其他安排：主实验中，Gemma3 在 50% 剪枝下重复码为 15%，高于交织 BCH 的 8.3%；Llama3.2 同一剪枝比例下，有序 BCH 为 100%，交织 BCH 为 93.3%。

## 指纹保留与模型可用性，需要分别判断

权重混合展示了消息恢复与核验通过的区别。在主实验中，当带指纹权重占比降至 0.25，四个模型的消息仍全部正确恢复、BER 为零，但检测率均为零：相关性没有达到固定门槛。占比为 0.5 时也全部恢复消息，检测率却仅为 28.3%–61.7%，反映临界信号强度对接受判定的影响。

缓存实验则展示了另一种分离。受控遮蔽仅保留 25% token 可见性时，四个模型的检测率与消息恢复率仍为 100%，但 Δ log PPL 上升至 4.897–5.963。第 0 层审计信号仍可读出，下一词预测却明显变差。因此，保留指纹不能替代模型效用评估；这组遮蔽实验也不能直接证明真实缓存删除或长上下文服务中的表现。

下游适配进一步说明了模型差异。我们在训练前写入指纹，分别进行英文、中文数据上的全参数监督微调（SFT）与 LoRA，并在第 1、3、5、7 轮使用冻结的提示审计集核验。第 7 轮中文适配后，Gemma3 的全参数 SFT 检测率为 40%，LoRA 为 80%；Qwen3 与 Llama3.2 对应结果均为 95% 和 100%。这些数据来自表 6、表 7，支持所测 LoRA 配置保留信号更好，也说明初始检测成功不能保证训练后的持久性。

本工作的价值，是让编码方案与实际变换一起接受检查，并把恢复内容、信号强度和预测质量连接起来。当前结果来自有限模型、种子和数据上的内部状态审计；更大模型、真实缓存移除、长上下文和任务级效果仍需进一步验证。对模型归属的判断，也应结合这些访问条件与证据范围。
