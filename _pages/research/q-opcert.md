# 指令被跳过时，如何约束 INT8 卷积的输出误差？

<p class="research-meta">DATE 2027 · <a href="{{ '/assets/pdf/Q-OpCert_Bounded-Error%20Output%20Integrity%20against%20Instruction%20Skips%20in%20INT8%20CMSIS-NN%20Convolution.pdf' | relative_url }}">论文 PDF</a></p>

微控制器上的神经网络推理常用 INT8 卷积来节省时间和内存。CMSIS-NN 把乘加、重定量化和写回组织成紧凑的指令序列。一次指令跳过就可能让卷积少累加一项，或让本次结果留在寄存器里、输出缓冲区仍保留旧值。程序有时会继续运行，下一层也可能照常读入这份错误的输出。

Q-OpCert 在卷积内核的三个阶段加上软件检查。先用通道校验和核验乘加结果，再用一条独立的计算路径核验重定量化，最后确认输出确实写到了预期位置。检查发现异常时，调用端可以拒绝该结果。对于通过检查的结果，我们关心它和无故障输出相差多少。

**在三种 Cortex-M33 卷积配置的最终复测中，1,971 个静态指令位置产生了 229,525 条试验记录，没有一次接受误差超过两个量化刻度（LSB）的输出。** 这里的一个 LSB 对应 INT8 输出相邻整数值之间的一格。

## 用一条较短的计算路径给出误差界

卷积先把输入与权重的乘积累加到 32 位整数，再按输出通道的比例因子缩放和舍入，最后把数值限制在允许的 INT8 范围内。重做一遍同样的重定量化可以逐值核验，但需要再次执行原来的计算。我们利用处理器上的舍入乘法构造一条更短的独立路径，生成一个参考输出。

在论文采用的两阶段重定量化方式和移位范围内，无故障参考输出与精确结果最多相差一个 LSB。检查器也只允许实际读回的数值与参考输出相差一个 LSB。把两个差值相加，就得到接受结果距无故障精确输出至多两个 LSB 的误差界。这一推导以参考计算和比较正常执行为前提。论文另对所实现算术域中的 6,292,480 组中间值与移位组合进行了可执行核对，观察到的最大精确值与参考值差为一个 LSB（原论文第 III 节）。

## 从乘加结果一直检查到内存写回

独立重定量化路径仍使用主路径的累加值。为检查这个共同输入，我们把同一次内核调用中各输出通道的累加值求和，再单独用预先计算好的权重校验和与偏置总和计算预期值。只要错误改变了这项总和，校验便会发现不一致。这样可以用一项线性关系检查整组累加结果，计算量低于逐通道重做卷积。多个累加误差在求和中抵消时，这项关系可能仍然成立。

输出端同时检查写入的值和目的地址。内核写回之后重新读取输出缓冲区，调用端也检查内核返回的指针是否恰好推进到下一段输出的起点。这两个检查分别覆盖本次结果的交付和后续调用使用的位置。各路异常记录汇入两份独立更新的状态，任一份保留异常证据，最终提交就拒绝本次结果。

## 板上试验如何检查误差界

我们在 STM32U575 开发板上测试三种卷积形状，覆盖多次内核调用与奇数输出宽度。每种配置在所选保护函数中枚举 657 个静态指令位置。每份测试固件只模拟一个位置被跳过，运行后将输出与独立的无故障参考结果比较。只要系统仍接受输出，且任一元素的绝对误差超过两个 LSB，就记为一次静默超界。

早期试验发现了五类检查盲点，其中几类与写回或指针有关。有的错误不会改变已经算出的数值，却会影响缓冲区实际收到什么，或后续调用从哪里继续写。由这些结果引出的设计修改，是把写回读值、精确目的地址和下一次调用的起始位置纳入接受条件。完成修订后，三种配置都重新枚举并运行了完整试验。

| 卷积配置 | 静态指令位置 | 记录试验数 | 静默超界次数 |
| --- | ---: | ---: | ---: |
| p0 | 657 | 76,655 | 0 |
| p1 | 657 | 76,335 | 0 |
| p4 | 657 | 76,535 | 0 |
| 合计 | 1,971 | 229,525 | 0 |

*数据来自原论文表 5。测试固件中有 171 份未产出试验记录、9 份提前终止，这些结果单独计入可用性。最终记录中有 14,256 次接受了误差为一或两个 LSB 的输出。*

## 增加检查需要多少计算周期

我们在两块板上比较无故障运行的周期数，每块板都使用自己的基线。独立重定量化检查在两块板上都比重新执行精确重定量化的开销低。完整设计还需要核验写回与指针，在 STM32U575 的小卷积测试中，周期数由 5,277 增至 7,601，开销为 44.040%。

| 检查配置 | STM32F407 周期增幅 | STM32U575 周期增幅 |
| --- | ---: | ---: |
| 独立重定量化 | 1.778% | 10.328% |
| 精确重定量化复算 | 1.982% | 12.450% |
| 独立重定量化与通道校验和 | 5.348% | 33.580% |
| 再加双路异常状态 | 5.445% | 34.319% |
| 完整设计，含写回与指针检查 | — | 44.040% |

*数据来自原论文表 3、表 4 及相应正文。两块板使用各自的处理器与编译配置，表中比例均相对于该配置对应的基线。*

对微控制器推理而言，输出完整性同时取决于算出的值、实际写出的值和写入位置。Q-OpCert 给这三个环节建立了同一个接受条件，并用明确的量化误差界检验输出。当前证据覆盖论文所列的算术域、CMSIS-NN 内核和三种静态指令跳过试验配置。物理故障注入下的表现、完整网络的任务精度以及故障后恢复属于进一步的评估问题。
